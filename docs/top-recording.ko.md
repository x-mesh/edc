# 자동 기록 종료 요약

`edc top --auto-record`를 실행하면 기존의 5분 사전 버퍼를 유지하고, load, swap-out, macOS 메모리 압박이 기존 시작 조건을 만족할 때 기록합니다. 자동 기록은 1분 동안 잠잠하면 끝납니다. `w`를 누르면 더 일찍 멈출 수 있으며, 시작 조건이 풀리기 전까지는 다시 시작하지 않습니다.

자동 실행이 끝나면 대시보드에 실행 ID와 커밋된 표본 수를 담은 짧은 알림이 나옵니다. `q`나 Ctrl-C로 대시보드를 나오면, 원래대로 돌아온 터미널에 마지막 자동 기록이 나옵니다.

- 관측한 시간 범위. 저장한 사전 버퍼와 잠잠했던 끝부분을 포함합니다.
- 처음 시작 조건과 커밋된 표본 수.
- 호스트 CPU 최고값과, 처음·최고·마지막 관측의 메모리 사용률.
- 읽을 수 있었던 process RSS 관측 중 가장 큰 값과 그 이름, PID. 관측한 최고값일 뿐, 증가율이나 메모리 누수 진단이 아닙니다.
- 기록을 받은 데이터베이스를 쓰는 `edc history overview --run <id> <DB>` 명령.

대시보드 세션 하나에서 자동 실행이 여러 번 끝나면, 보고는 전체 수를 밝히고 마지막 것만 보여 줍니다. 이전 실행은 이력 데이터베이스에 남아 있습니다. 마지막 요약 하나와 실행마다 크기가 정해진 통계만 두므로, 모든 표본이나 종료 보고를 메모리에 쌓지 않습니다.

요약은 데이터베이스 transaction이 커밋된 표본만 셉니다. queue, 쓰기, 닫기가 실패하면 불완전하다고 표시하고, 기존처럼 0이 아닌 종료 코드를 냅니다. 이 경우에도 커밋된 관측은 보고할 수 있습니다. 읽지 못한 process 값은 RSS가 0인 process가 아니라 알 수 없음으로 표시합니다. 커밋된 표본이 없는 기록은 그렇다고 밝힙니다.

수동으로만 한 기록은 기존 출력을 그대로 씁니다. 자동 실행 뒤에 수동 기록을 멈춰도 마지막 자동 보고를 바꾸지 않습니다.

보고의 설명 칸은 터미널 폭에 맞춰 줄바꿈하고, 색 없이도 읽을 수 있습니다. 다시 볼 명령은 줄바꿈을 넣지 않고 출력하므로, 공백이나 작은따옴표가 든 경로를 따옴표로 감싼 그대로 복사할 수 있습니다. 화면에서는 터미널이 줄을 접어 보일 수 있습니다. 제어 문자가 든 경로는 원래의 제어 문자를 터미널에 보내지 않고, Bash/Zsh의 ANSI-C 인용(`$'...'`)으로 표시합니다.
